渐进负荷

专注个人健身力量训练记录原生级APP
导入其他 App 记录 · 使用步骤

这是什么

把你在其他训练 App（如 Hevy、训记等）里的历史训练记录迁移到「渐进负荷」：力量训练会按动作和每一组的重量、次数完整导入，有氧记录按分钟数导入。

导入只追加训练记录，不影响你的档案、训练计划和已有数据；同一天有重叠时会先询问你保留哪一份。

适用于能让 AI 读取到按组训练记录的 App（以训记为例，其他 App 流程相同）。

使用步骤

  1. 在原训练 App 里获取 Skill 文档
    在要导出的 App 中找到「Skill / Agent 数据导出」入口（以训记为例：我的 → 数据导出和导入），把它的 Skill 文档导出（可发到微信文件再转存电脑）。各 App 入口位置可能不同。
    训记 App：我的 → 数据导出和导入
    导出 Skill 文档（文件已含访问 Key）
  2. 把 Skill 文档发给电脑端的 AI Agent
    在电脑端打开 AI Agent 软件（如 Kimi Work、DeepSeek Harness、WorkBuddy 等支持 Skill 的客户端，网页对话版不适用），把上一步的 Skill 文档拖进对话发送。它询问用途时直接点「跳过」。
    AI 询问用途时，点「跳过」即可
  3. 再发送导入 skill 并生成 JSON
    先把 progressive-load-import.skill.md（下方按钮下载）拖进同一对话发送。AI 会自动把动作名匹配到「渐进负荷」的内置动作，稍等片刻即可收到 progressive_load_import_日期.json 导入文件和一段导入说明。
    下载 progressive-load-import.skill.md

    7.6 KB · 保存后在下一步拖进 AI 对话

    生成的 JSON 导入文件（示例）
  4. 把 JSON 文件保存到 iPhone / iPad
    用微信文件传输、隔空投送或邮件把 .json 文件发到手机，在手机上用「文件」App 保存（文件名需以 .json 结尾）。
  5. 在「渐进负荷」里导入
    打开「渐进负荷」→ 底部「我的」→「数据管理」→「导入其他 App 记录」，选中刚保存的 JSON 文件。
  6. 处理日期重叠（如有）
    遇到已存在的日期时按提示选择：不确定就选「保留原数据」，不会删除任何已有记录。
  7. 完成
    看到「成功导入 X 天数据」即完成。如需撤销，可在「数据管理」→「删除其他 App 的记录」一键移除本次导入的全部记录。

常见问题

能导入哪些内容？
  • 力量训练：日期、动作（自动匹配内置动作与器械）、每组的重量与次数；
  • 有氧：按天汇总的分钟数与类型说明；
  • 组间休息、RPE、备注等细节不迁移（源数据不含这些口径）。
「导入文件」和「导入其他 App 记录」有什么区别？

「导入文件」是全量替换：先删除本机全部数据再采用文件内容，用于恢复备份。「导入其他 App 记录」只追加训练记录，用于从别的 App 迁移历史。两者不要混淆。

同一个文件重复导入会怎样？

同一天的数据重叠时会弹出选择：保留原数据、采用新记录或保留两者。不确定就选「保留原数据」，不会丢任何记录。

AI 生成的文件导入失败怎么办？

请把失败提示截图，通过技术支持页底部的联系方式发给我们；也可以让 AI 重新生成（它会按 skill 里的自检清单校验后再输出）。

ProgressiveLoad

A native-grade app for personal strength training logs
Import from Another App · How To

What this is

Move your training history from another training app (e.g. Hevy) into ProgressiveLoad: strength workouts are imported with each exercise and every set's weight and reps, and cardio is imported as daily minutes.

Importing only adds training records — your profile, plans and existing data are untouched. If a date overlaps, you choose what to keep first.

Works with any app whose per-set training records an AI can read (Xunji shown as an example; the flow is the same for others).

Steps

  1. Get the skill document from your training app
    In the app you want to export from, find its “Skill / Agent data export” entry (e.g. in Xunji: Profile → Data Export & Import) and export the skill document (you can send it to WeChat File Transfer, then to your computer). The exact location varies by app.
    Xunji app: Profile → Data Export & Import
    Export the skill document (access key included)
  2. Send the skill document to an AI agent on your computer
    On your computer, open an AI agent client that supports skills (e.g. Kimi Work, DeepSeek Harness, WorkBuddy — web chat pages don't apply), and drop the skill document into the conversation. When it asks what you want to do, just tap “Skip”.
    Tap “Skip” when the AI asks what to do
  3. Send the import skill and get the JSON
    First download progressive-load-import.skill.md (button below) and drop it into the same conversation. The AI matches exercise names to ProgressiveLoad's built-in exercises and, after a short wait, returns a progressive_load_import_YYYYMMDD.json file with import instructions.
    Download progressive-load-import.skill.md

    7.6 KB · save it, then drop it into the AI conversation

    The generated JSON import file (example)
  4. Save the JSON file to your iPhone / iPad
    Send the .json file to your phone via WeChat File Transfer, AirDrop or email, and save it in the Files app. The file name must end with .json.
  5. Import in ProgressiveLoad
    Open ProgressiveLoad → “Profile” tab → “Data Management” → “Import from Another App”, and pick the JSON file you saved.
  6. Resolve date overlaps (if any)
    When an existing date overlaps, follow the prompts: choose “Keep existing” if unsure — nothing you already have will be deleted.
  7. Done
    “Successfully imported X days of data” means it worked. To undo, use “Delete Imported Records” in Data Management to remove everything from this import at once.

FAQ

What gets imported?
  • Strength training: date, exercise (auto-matched to built-in exercises and equipment), and weight & reps for every set;
  • Cardio: daily total minutes and a short note;
  • Rest times, RPE and notes are not migrated (the source format doesn't carry them).
“Import File” vs. “Import from Another App”?

“Import File” replaces everything: it deletes all current data and adopts the file — use it to restore a backup. “Import from Another App” only adds training records, for migrating history from another app. Don't mix them up.

What happens if I import the same file twice?

Overlapping dates prompt a choice: keep existing, use the new record, or keep both. “Keep existing” is always safe — nothing gets lost.

What if the AI-generated file fails to import?

Take a screenshot of the failure message and send it to us via the contact options at the bottom of the Support page; or ask the AI to regenerate (it self-checks against the checklist in the skill before output).
